A simple Python object-oriented vehicle-rental program.

Open a terminal in the `Assignment_02` folder and run:

```bash
python main.py
```

The program contains four classes:

* `Vehicle`
* `Renter`
* `ElectricCar`
* `Motorbike`

It demonstrates encapsulation, inheritance, and polymorphism.

I used AI to help explain the assignment requirements and understand Python concepts such as classes, `@property`, inheritance, `super()`, and polymorphism. I wrote and tested the code myself.
